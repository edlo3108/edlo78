# 股票買賣時機分析器

這個專案提供一個簡潔的網頁工具，協助使用者從一串股價資料中找出潛在的最佳買賣時機，同時提供常見績效指標供參考。

## 功能特色
- 支援以逗號、空白或換行輸入每日價格。
- 自動計算最佳單筆交易的買進/賣出時點與獲利。
- 可設定最大顯示交易筆數與最小價差，用以過濾雜訊。
- 顯示總報酬率、日均報酬率、波動度與最大回檔等統計資訊。

## 使用方式
1. 在瀏覽器中開啟 `index.html`。
2. 將每日收盤價貼到輸入框中（支援逗號或換行分隔）。
3. 視需要調整交易上限與最小價差。
4. 按下「開始分析」即可取得建議交易與統計數據。
